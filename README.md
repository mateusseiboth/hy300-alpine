# hy300-alpine

Alpine Linux como ambiente de recuperação e instalação do projetor HY300 (Rockchip RK3566),
gravado na partição `recovery`. Sobe com o kernel 6.1 do HY300
([kernel-hy300-rk3566](https://github.com/mateusseiboth/kernel-hy300-rk3566)), conecta no Wi-Fi e
abre SSH; dali se faz backup, instalação do sistema principal e testes de hardware, e o kexec
de kernels de teste.

Projeto principal e documentação: [hy300-rk3566](https://github.com/mateusseiboth/hy300-rk3566).
